# Adult ADHD Research Toolkit: Journals, Topic Positioning, Keywords, and Search Templates

**Scope:** adult attention-deficit/hyperactivity disorder (adult ADHD) across medicine, psychiatry, neuroscience, psychology, sociology, public health, health services, education, occupational functioning, addiction, sleep, and digital health.

**Date created:** 2026-05-09  
**Language:** English  
**File purpose:** a copy-paste-ready literature-search toolkit for PubMed, Google Scholar, Scopus, Web of Science, APA PsycInfo, Embase, Cochrane Library, CINAHL, Semantic Scholar, Dimensions, and Europe PMC.

> Practical note: no static list can literally include every possible journal that may publish one adult ADHD article. This file is designed as a comprehensive, high-yield, clinically useful directory of journals and reusable search templates. For systematic reviews, always add database-specific controlled vocabulary, run backward/forward citation chasing, and document the final search date.

# Recommended Core Concept Block

Use this as the starting block for most adult ADHD searches.

```text
(
  "Attention Deficit Disorder with Hyperactivity"[Mesh]
  OR ADHD[tiab]
  OR "attention deficit hyperactivity disorder"[tiab]
  OR "attention-deficit/hyperactivity disorder"[tiab]
  OR "adult ADHD"[tiab]
)
AND
(
  adult[MeSH Terms]
  OR adult*[tiab]
  OR adulthood[tiab]
  OR "young adult"[MeSH Terms]
  OR "middle aged"[MeSH Terms]
  OR "older adults"[tiab]
)
```

## 2. Google Scholar templates

Google Scholar is useful for broad discovery, citation chasing, and grey literature. Use quotation marks for exact phrases, `intitle:` for title searching, `author:` for author searching, and Advanced Search for journal/source and year limits.

### 2.1 Broad search

```text
"adult ADHD" OR "adult attention deficit hyperactivity disorder"
```

### 2.2 Focused topic search

```text
"adult ADHD" "executive function" "working memory"
```

```text
"adult ADHD" "emotional dysregulation" "depression" "anxiety"
```

```text
"adult ADHD" "cognitive behavioral therapy" OR CBT
```

### 2.3 Journal-limited Google Scholar workflow

Use Google Scholar → Advanced Search:

```text
Exact phrase: adult ADHD
With all of the words: executive function working memory
Published in: Journal of Attention Disorders
Date range: 2020–2026
```

### 2.4 Title-focused search

```text
intitle:"adult ADHD" intitle:treatment
```

```text
intitle:"adult ADHD" intitle:meta-analysis
```

### 2.5 Citation-chaining workflow

1. Search: `"adult ADHD" "systematic review"`.
2. Open a key review.
3. Click **Cited by**.
4. Add search-within-citing-articles terms such as `women`, `sleep`, `workplace`, `substance use`, or `fMRI`.

# Quality-Control Checklist for Searches

- Start broad, then add one concept block at a time.
- Check PubMed **Search Details** to see whether automatic term mapping changed the query.
- Use both controlled vocabulary and free text: MeSH in PubMed, APA Thesaurus in PsycInfo, Emtree in Embase.
- Search title/abstract fields for precision; search all fields for sensitivity.
- Do not rely only on `"adult ADHD"`; also search the full disorder name and MeSH heading.
- For medication searches, include both generic drug names and class terms.
- For social-science questions, search PsycInfo, Scopus, Web of Science, and Google Scholar in addition to PubMed.
- For qualitative work, include `interview*`, `lived experience`, `phenomenolog*`, `ethnograph*`, and `narrative`.
- For systematic reviews, save the exact final query, search date, database, interface, and number of records retrieved.
- For Taiwan or East Asia, include both country terms and broader regional terms.
